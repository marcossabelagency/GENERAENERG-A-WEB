# Eyebrow

Antetítulo en píldora con punto lima que sitúa al lector antes de un titular.

**Marcado:** `<span class="g-eyebrow">Texto</span>`; `g-eyebrow--plain` quita borde y fondo (dentro de tarjetas). Texto en minúsculas en el HTML: el CSS lo pasa a mayúsculas con tracking 0.18em.

Máx. 3 palabras. Va siempre encima de un `h1`/`h2`, con `space-4` de separación. No lo uses como botón ni como etiqueta de estado.
