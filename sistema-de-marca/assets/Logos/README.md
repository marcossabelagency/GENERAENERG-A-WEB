# Logos

Logotipos de Genera Energía, a partir de los PNG facilitados por el cliente (diseño de Daniela). Fondo blanco eliminado; el rayo interior de la hoja queda en blanco opaco para que se lea sobre cualquier fondo.

- `genera-logo-horizontal.png`: versión principal, sobre `surface-000` y `surface-100`.
- `genera-logo-horizontal-negativo.png`: textos en `white`, sobre `surface-inverse`, fotos oscuras y tema oscuro.
- `genera-logo-vertical.png` / `genera-logo-vertical-negativo.png`: footer centrado, redes, piezas cuadradas.
- `genera-simbolo.png`: hoja sola, 250×250 con aire. Favicon, avatar de Google Business y redes.

Son PNG de ~350px de ancho: válidos para web hasta ~180px de ancho mostrado. Para impresión o tamaños mayores hace falta el original vectorial (SVG/AI/PDF).
