# Genera Energía · Web

Web de Genera Energía, instalación de placas solares en la Marina Alta.

- `index.html`: la Home completa. Se publica tal cual en cualquier hosting estático (Netlify, Vercel, GitHub Pages).
- `assets/` y `fonts/`: logos y tipografías que usa la web.
- `marca/logos/`: todas las versiones del logo (positivo, negativo y símbolo).
- `sistema-de-marca/`: colores, tipografía, espaciados, componentes y guía de marca (`README.md`).

Detalles, datos editables y pendientes en [LEEME.txt](LEEME.txt).
