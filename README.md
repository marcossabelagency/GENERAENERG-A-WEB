# Genera Energía · Web V1

Web de Genera Energía, instalación de placas solares en la Marina Alta. Web estática (HTML, CSS y JavaScript), sin dependencias: se publica tal cual en cualquier hosting (Netlify, Vercel, GitHub Pages).

| Página | Archivo |
|---|---|
| Home | `index.html` |
| Equipo | `equipo.html` |
| Nuestro trabajo | `trabajo.html` |
| Proyectos destacados | `proyecto-vivienda.html`, `proyecto-empresa.html`, `proyecto-comunidad.html` |
| Contacto | `contacto.html` |
| Legales | `aviso-legal.html`, `privacidad.html` |

- `assets/` y `fonts/`: logos y tipografías que usa la web.
- `marca/logos/`: todas las versiones del logo.
- `sistema-de-marca/`: colores, tipografía, componentes y guía de marca.

Toda la web está en español e inglés (selector ES/EN en la barra de navegación). Datos editables y pendientes en [LEEME.txt](LEEME.txt).
